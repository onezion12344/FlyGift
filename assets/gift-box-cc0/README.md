# GiftBox 3D model

`GiftBox.obj` is the “Gift Box 3D model” by ETechStudios, downloaded from:

https://etechstudios.itch.io/giftmodel

The original download also contains Blender and FBX versions. FlyGift ships the
OBJ mesh only and supplies its own SceneKit materials and animation.

The author released the asset under Creative Commons Zero v1.0 Universal
(CC0/public domain):

https://creativecommons.org/publicdomain/zero/1.0/
